# 🌟 RAZ 阅读大冒险

一个为 5–8 岁孩子设计的英语分级阅读测试小游戏，纯静态网页，无需安装、无需注册。

**在线试玩**：`https://<你的用户名>.github.io/raz-reading-game/`

## 玩法

1. 首页选一个级别（C / D / E / F / G）
2. 三关挑战（每局随机组卷）：
   - **第 1 关 · 单词认读**：看图选词 × 10
   - **第 2 关 · 句子理解**：选词填空 + 句意配图 × 8
   - **第 3 关 · 阅读理解**：原创短文 1 篇 + 理解题 × 5
3. 答对 +1⭐；答错 −1⭐ 并红框禁用该选项，可重选，选对才能进下一题
4. 正确率 ≥90% 会提示挑战下一级别

## 题库说明

- **全部原创**（单词题、句子题、短文），难度对标 Learning A-Z · RAZ Leveled Books 各级别标准
- 每级题库：20 道单词题 + 12 道句子题 + 3 篇短文（各配 5 道理解题），每局随机抽题
- 级别难度递进：C（高频词、重复句型）→ G（复合句、顺序/因果词）

## 存档说明

- 成绩自动保存在**每个人自己浏览器**的本地存储中：每个打开链接的人都有独立存档，互不干扰
- **家长报告**：正确率趋势折线、薄弱词统计、最近记录
- **存档码**：换设备时，在旧设备"家长报告 → 导出存档码"，在新设备粘贴导入即可迁移成绩

## 本地运行

直接双击 `index.html` 用浏览器打开即可，无需任何服务端。

## 如何添加新级别

在 `content/` 下按 `level-X.js` 的结构新增内容包，并在 `index.html` 中：

1. 加入 `<script src="content/level-X.js"></script>`
2. 把级别字母加入 `ALL_LEVELS` 数组
